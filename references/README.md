# Reference PDFs

These are the original practical writeups used as reference while building the scripts and notes. The copies here have been **sanitized**:

- Student names and roll numbers were redacted.
- The OpenWeatherMap API key was redacted.
- PDF metadata (author/title/subject/creator/producer) was cleared.
- Filenames were replaced with neutral experiment names.

The authoritative, runnable code is in [`../machine_learning/`](../machine_learning/) and [`../dmv/`](../dmv/); the notes are in the `notes/` folders.
